# Nuvotech Website

Sitio corporativo de una sola página para **Nuvotech Colombia**.

## Stack

Misma base que `seeon-landing-page`:

- Next.js 16
- React 19
- Tailwind CSS 4
- Motion
- Componentes UI / landing compartidos (Button, SectionReveal, HeroSpotlight, NumberTicker, etc.)

Sin theme switcher: tema oscuro fijo, igual que la landing de SeeOn.

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).
